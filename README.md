One image of the world’s news on Wednesday 18 November 2026. `main.py` copies the committed PNG to `/output/entry.png`. The picture, the sources, and the copy program are the entry for make.fun’s “Sum up 18 November's world news in one image” bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Outside the grader, `MAKEFUN_OUTPUT_DIR` stands in for `/output`. On the grader the same program writes `/output/entry.png`. Both runs copy one file, so the bytes match. Stories and the pages they come from are in [SOURCES.md](SOURCES.md).
